Проверять production `dist/index.html`, а не только dev-сервер. Результаты и аппаратная среда записываются в TEST-REPORT.md.

Дополнительные сценарии: быстрое переключение времени посреди перехода; движение по небу и панели; смена качества при паузе; потеря/восстановление WebGL-контекста; повторное открытие с сохранёнными настройками.

Ручная проверка на Windows с Lively: импорт ZIP, мышь за значками, запуск ярлыков, настройки после перезапуска, остановка при полноэкранном приложении, возврат, изменение разрешения, второй монитор. Эти пункты нельзя считать пройденными по одной браузерной проверке.

Финальная полировка: проверить асимметрию кроны и плавные ветви в трёх режимах;
слабую лунную подсветку, отсутствие широкого голубого пятна при проводке;
новые модульные проверки ограничителя пикселей и плавности/границ LOD.
В браузере проверить четыре группы травы, бюджет буфера, адаптацию под нагрузкой,
смену качества при паузе и восстановление WebGL с новыми материалами LOD.
